# Projet RED — Dungeon Edition

Cette version graphique utilise des sprites du pack DungeonTilesetII fourni avec le projet.

## Nouveautés
- Donjon en pixel-art avec sol et murs.
- Personnage Doc animé.
- Ennemis animés : citrouille, zombie et chevalier.
- Plusieurs types de monstres avec statistiques différentes.
- Coffre donnant de l'or et une potion.
- Pièce d'or ramassable.
- Récompense d'or après un combat.
- Barres PV / mana / XP améliorées.
- Écran de titre et HUD retravaillés.
- Sprites intégrés dans l'exécutable avec `embed`, donc pas de chemin d'asset à configurer.

## Contrôles
- Flèches ou WASD : déplacement
- Echap : pause
- 1 : attaque
- 2 : sorts
- 3 : inventaire
- 0 : retour dans les sous-menus de combat
- Entrée / Espace : continuer après un combat

## Lancer
Depuis la racine du projet :

    go run ./graphique

Le projet conserve également le programme console existant à la racine.
